INPUT:
    Video recordings of the printing process
    Monitored layer range L03-L10
    Number of sampling positions, Ns = 30
    Fixed CV processing parameters

OUTPUT:
    Layer-thickness measurements
    Layer-deformation values
    MLTD time series
    Overall MLTD slope
    Last-two-point MLTD slope

1. Extract one image snapshot after completion of each printed layer.

2. For each snapshot:
      a. Apply foreground segmentation using the pretrained U2-Net model.
      b. Obtain the region containing the printed element.
      c. Convert the cropped image to grayscale.
      d. Apply Gaussian smoothing to reduce image noise.
      e. Apply Canny edge detection.
      f. Apply the probabilistic Hough transform to identify approximately
         horizontal inter-layer boundaries.
      g. Use the detected boundaries to crop layers L03-L10.

3. For each monitored layer i and snapshot Xj:
      a. Define 30 uniformly spaced horizontal sampling positions.
      b. At each sampling position s:
             Identify the upper layer boundary Y_upper(s, Xj).
             Identify the lower layer boundary Y_lower(s, Xj).
             Calculate layer thickness:

             T_i(s, Xj) =
                 Y_upper(s, Xj) - Y_lower(s, Xj)

4. Define the initial thickness of layer i at each sampling position
   using the first valid monitoring snapshot X1.

5. For every subsequent snapshot Xj, calculate percentage deformation:

       D_i(s, Xj) =
           100 × [T_i(s, X1) - T_i(s, Xj)] / T_i(s, X1)

6. Calculate Maximum Layer Thickness Deformation:

       MLTD_i(Xj) =
           maximum D_i(s, Xj) over all valid sampling positions s

7. Calculate the overall MLTD slope for each layer:

       S_overall,i =
           [MLTD_i(Xf) - MLTD_i(X2)] / [tf - t2]

8. Calculate the incremental last-two-point slope:

       S_i(tj) =
           [MLTD_i(Xj) - MLTD_i(Xj-1)] / [Xj - Xj-1]

   where Xj - Xj-1 = 1 layer-deposition interval.

9. Store all thickness, deformation, MLTD, and slope values.
