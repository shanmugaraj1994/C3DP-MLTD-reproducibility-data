# Representative data for MLTD-based buildability failure prediction

Supporting manuscript: "Buildability Failure Prediction and Supervisory Decision-Support in Concrete 3D Printing Using Image Data".

## Contents and scope
- `images_representative/stable/`: 30 representative image frames.
- `images_representative/collapsed/`: 18 representative image frames.
- `representative_data/`: MLTD values for layers L03-L10, supplied as CSV files.
- `pseudocode/`: image-processing and cumulative collapse-warning procedures.
- `parameters/cv_and_prediction_parameters.txt`: processing and warning settings.

## Software
The described workflow uses Python, OpenCV, NumPy, pandas, Pillow, and the pretrained U2-Net full model.
